# DouyinFire

[简体中文](README.md) | [English](README.en.md)

Mac 上的本地抖音续火花工具。通过网页选择私聊联系人或群聊、设置消息和每日执行时间，日常使用无需终端。

- **列表选择**：私聊和群聊均可从会话列表中选择，自动核实绑定。
- **静默运行**：首次登录时打开浏览器，正常运行使用无界面的 Chromium。
- **多账号与防重复**：账号登录状态独立保存，同一天已确认发送的对象会自动跳过。

使用 Playwright 操作网页元素，不依赖像素坐标。可选接入 DeepSeek Flash，在指定时间内回复白名单私聊。

## 安装

目前需从源码在 macOS 上构建；以下步骤使用 **Python 3.13**，已在 Apple Silicon Mac 验证。生成的应用包含 Python 和 Chromium，日常运行无需另装环境。

在终端执行一次：

```bash
git clone https://github.com/lbf-sss/autodouyin.git
cd autodouyin
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt -r scripts/requirements-build.txt
python -m playwright install chromium
python scripts/build_macos.py --output "$HOME/Applications"
```

完成后双击 `~/Applications/DouyinFire.app`，应用会打开本地控制页。应用使用本地签名，未进行 Apple 公证。请将应用保存在本机非同步目录，避免 iCloud 等同步服务影响签名和运行。

## 首次使用

1. **登录账号**：添加账号，点击“扫码登录”，在浏览器中完成扫码或平台验证。
2. **设置消息**：填写默认消息。联系人也可设置单独的消息，留空则使用默认消息。
3. **选择对象**：点击“添加联系人”，选择“私聊”或“群聊”，点击“保存修改”。再点“选择联系人”或“选择群聊”，选中目标并点击“核实并绑定”。名称会自动带入，无需预先填写或复制主页链接。
4. **试发一次**：仅勾选一个已绑定的对象，保存后点击“立即执行”。到抖音确认对象和消息正确，再添加其他对象或开启每日任务。

读取列表和绑定不会发送消息。遇到同名对象时，请核对列表中的身份标识；切换私聊／群聊类型后需要重新绑定。

## 抖音互动表情

在“默认消息”的类型中选择“抖音互动表情”，再选择或填写“续火花”“比心”“在干嘛”等名称。联系人也可单独选择表情；联系人消息和表情都留空时使用账号默认内容。点击“保存修改”后才会生效。

互动表情会单独发送，不与文字拼成一条消息。表情必须出现在当前账号、当前会话的抖音互动表情分类中，名称须完全一致；找不到、同名或身份无法核实时会停止，不会改发普通文字。目前不支持带随机结果的“摇骰子”和“猜拳”。

读取和准备表情不会发送；“立即执行”或已启用的定时任务才会发送。发送成功需要核实平台的新消息回执；结果不明会进入“待核实”，不会自动重发。每天去重同时适用于文字和表情。

互动表情名称需要与当前账号可用面板一致；不同账号和平台版本的可用项目可能不同。

## DeepSeek 自动回复

在“AI 自动回复”中保存 DeepSeek API Key，单独勾选已绑定的私聊联系人，并设置回复时间（默认北京时间 19:00–21:00）。选择联系人后，点击“读取本人历史文字”，检查或编辑语气样本，再勾选开启并保存设置。修改密钥、样本或联系人绑定会暂停自动回复，需再次开启。

白名单不要求每位联系人预先拥有专属语气样本。没有专属样本时，使用账号整体语气统计；整体样本也不足时采用自然、克制的表达。自动检查消息期间设置区会暂时锁定，可先点“立即暂停自动回复”，等待任务停止后勾选或取消联系人，再勾选开启并保存设置。

支持待回复的文字、聊天中显示的图片、表情包和抖音视频分享。媒体按当前绑定账号和联系人核对，使用临时画面交给 `deepseek-flash`，不把媒体学成本人说话样本。单批最多 4 条媒体消息、12 张画面，每张最多 2 MiB、合计最多 8 MiB；超限时不发送，不把未处理消息标记为已回复。

视频通过分享的已核实视频 ID 打开原站详情页，抽取最多 3 帧，最长抽样前 90 秒；视频评论分享还可读取评论截图。第一版不听取或转写音轨。不可播放时只参考封面并明确标注；封面也不可见时说明内容未知，不声称看过完整视频。图片与表情包目前读取聊天中已显示的画面，可能受缩略图清晰度影响。媒体画面随当前会话提交给 DeepSeek，勿将图片/视频中的文字指令当作系统规则。

可手动保存每位联系人的 50 条语气样本，也可点击“从历史学习我的语气”，读取当前账号已保存、启用并绑定的私聊会话。每个会话最多重叠滚动 12 屏、保存 600 条本人文字；网页可能只提供部分历史，页面显示实际覆盖条数，不保证完整导出。自动学习仅采用本程序首次 AI 回复尝试之前的本人文字，避免把 AI 输出反复学成你的语气。学习不增加发送白名单，也不改变开启状态或回复时段。

Key 和历史语气样本保存在本机权限为 0600 的私有文件中；Key 不回显，也不进入配置或日志。回复时向 DeepSeek 官方接口（`deepseek-flash`）提交当前会话的近期上下文（通常 60 条，连同全部待答文字最多 100 条）、时间、最多 18 条当前联系人的相关本人样本，以及其他会话在本机提取的句长、标点等汇总特征；其他会话原文不随此请求提交。超出上下文限制时停止此次发送，不把未交给模型的问题标记为已回复。

应用与可复用的 `contextual-chat-style` skill 共用 `douyinfire/skills/contextual-chat-style/references/reply-rules.md`：先理解指代、时间、最新纠正和所有待答消息，再模仿表达方式；风格样本不能作为当前行程、位置或承诺的事实依据。规则随应用打包，缺失时停止生成。

约每 30 秒串行检查一次，处理最后一次本人回复之后尚未答复的对方文字，包括开启、重启或修改设置前已有的消息；只读取当前已加载的聊天；支持上述图片、表情和视频画面处理，暂不处理语音或视频音轨。连续来信合并生成一条回复，自动“续火花”不当作已回复。你已手动回复、生成期间消息变化、暂停或超出时间段时，会放弃旧草稿。确定尚未发出的失败会在后续轮询重新检查；已经确认发送或结果不明的提交绝不自动重发。

点击“立即暂停自动回复”可随时停止。回执不明会暂停该联系人，需在抖音核实后手动解除；解除后继续检查其他尚未回复的文字，这条已人工核实的原提交仍不会自动重发。自动回复与每日续火花独立记录。Mac 必须保持唤醒，后台必须运行；语气相似度取决于样本，建议先检查样本。功能默认关闭。

## 每日自动执行

在“每天自动执行”中设置时间，勾选“开启”并点击“保存时间”。默认关闭自动执行，默认时区为香港时间；时间浮动和发送间隔可在“设置与运行详情”中调整。

每日任务会处理所有启用账号中勾选的联系人；“立即执行”只处理当前账号。

- **关闭网页**：后台继续运行。
- **重启电脑后恢复**：在“设置与运行详情”中点击“开启登录后后台运行”，登录 macOS 后恢复运行。
- **电脑睡眠**：睡眠期间无法执行；唤醒后仅在当天补执行窗口内补跑，默认 180 分钟，不补发往日任务。
- **退出后台**：停止后台，同时关闭每日任务、AI 自动回复和登录后恢复。再次使用自动执行时，需要重新开启。

## 查看发送结果

| 状态 | 含义与处理 |
| --- | --- |
| 已发送 | 已取得平台可核实的发送结果。 |
| 已跳过 | 例如该账号今天已向同一对象发送过消息，无需再次发送。 |
| 未发送 | 查看提示并处理原因后，可重试明确未发送的任务。 |
| 待核实 | 发送可能已经发生；该账号停止本次后续发送，并暂停该对象重试。请先到抖音查看。 |

对“待核实”记录，确认后选择“我已核实：已发送”或“我已核实：未发送”。选择未发送只解除暂停，仍需手动执行；重启或跨日不会自动重发。

同一天修改昵称或消息不会绕过去重。重新绑定了发送对象后，请使用“立即执行”开始新任务，旧失败记录不会转发给新对象。任务运行中可点击“停止任务”；已经进入发送阶段的记录仍可能需要核实。

## 常见问题

**列表里找不到联系人或群聊？**

列表只包含抖音网页当前已加载的会话，不是完整好友名单。先在该账号的抖音网页中打开目标会话，再点击“重新读取”。私聊也可以展开“使用主页链接”进行绑定；群聊无需个人主页链接。

**登录过期或出现验证码怎么办？**

点击“扫码登录”完成平台验证，再用“检查连接”确认状态。应用不会绕过验证码；抖音页面变化或无法确认收件人时，会停止操作并提示原因。

**账号和消息记录保存在哪里？**

默认保存在 `~/Library/Application Support/DouyinFire/`。配置、登录状态和发送记录都保存在本机，不要将该目录上传到仓库或在浏览器运行时同步、替换。启动器发现旧版项目时，会先备份再迁移可用数据，并要求重新核对账号和联系人；旧版成功日志不作为已确认发送记录。

**怎样更新或移动应用？**

先在控制页点击“退出后台”，再重新构建或移动应用。重新打开后，如需自动执行，请重新开启每日任务和登录后后台运行。

## 开发

在已安装依赖的项目虚拟环境中，可直接运行源码或测试：

```bash
python -m douyinfire.desktop
python -m pytest -q
python -m douyinfire.cli doctor
```

自动化测试使用合成数据，不会向真实联系人发送消息。`doctor` 仅检查浏览器运行环境，不登录抖音或发送消息。配置示例见 [config/douyinfire.example.yaml](config/douyinfire.example.yaml)。
